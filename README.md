# 💵 Thai Banknote Scanner (ระบบสแกนธนบัตรไทย AI)

เว็บแอปพลิเคชันสแกนและจำแนกชนิดราคาธนบัตรไทย (20, 50, 100, 500 และ 1,000 บาท) แบบเรียลไทม์ด้วย AI ผ่านกล้องสมาร์ทโฟนหรืออัปโหลดรูปภาพ พร้อมระบบอ่านออกเสียงภาษาไทยและระบบสั่นแจ้งเตือน

## 🌟 ฟีเจอร์เด่น (Key Features)

- **AI จำแนกธนบัตรไทย 5 ชนิดราคา:**
  - 🟢 **20 บาท** (ธีมสีเขียว)
  - 🔵 **50 บาท** (ธีมสีฟ้า/น้ำเงิน)
  - 🔴 **100 บาท** (ธีมสีแดง)
  - 🟣 **500 บาท** (ธีมสีม่วง)
  - ⚪ **1,000 บาท** (ธีมสีเทา/น้ำตาล)
- **สแกนกล้องสดบนมือถือ (Live Camera Scanner):**
  - รองรับกล้องหลัง (`facingMode: "environment"`) เป็นค่าเริ่มต้น
  - มีปุ่มสลับกล้องหน้า/กล้องหลัง (📷)
  - กรอบเล็งธนบัตร (Viewfinder) พร้อมเลเซอร์สแกนจำลอง
- **สแกนจากไฟล์รูปภาพ (Upload Image Mode):**
  - อัปโหลดไฟล์รูปภาพธนบัตรจากเครื่อง หรือเลือกจากแกลเลอรีภาพถ่ายเพื่อจำแนกได้ทันที
- **ระบบเสียงอ่านออกเสียงภาษาไทย (Text-to-Speech):**
  - อ่านออกเสียงทันทีผ่าน Web Speech API เช่น *"ธนบัตรหนึ่งร้อยบาท"*, *"ธนบัตรยี่สิบบาท"*
  - มีระบบหน่วงเวลา (Debounce / Cooldown 2.6s) ป้องกันเสียงอ่านซ้ำรัวๆ
- **ระบบสั่นแจ้งเตือน (Haptic Feedback):**
  - สั่นเตือนนุ่มนวล 2 จังหวะเมื่อจำแนกธนบัตรสำเร็จ
- **หน้าจอแสดงผลขนาดใหญ่พิเศษ (High Accessibility):**
  - ตัวเลขขนาดใหญ่ยักษ์ เหมาะสำหรับผู้สูงอายุหรือผู้พิการทางสายตา
  - แสงออร่าพื้นหลังและขอบจอเปลี่ยนสีตามธนบัตรแบบ Dynamic
  - แถบความมั่นใจ (Confidence Score) และตารางแสดงความน่าจะเป็นแบบเรียลไทม์

## 🚀 วิธีเปิดใช้งาน

### 1. ทดสอบบนเครื่องคอมพิวเตอร์ (Localhost)
ใช้ Python เพื่อเปิด Web Server ในโฟลเดอร์นี้:
```bash
python -m http.server 8000
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:8000`

### 2. ทดสอบบนสมาร์ทโฟน (ผ่าน HTTPS)
เนื่องจากเบราว์เซอร์บนมือถือต้องการการเชื่อมต่อแบบ **HTTPS** เพื่อขอสิทธิ์เข้าถึงกล้อง สามารถใช้ Cloudflare Tunnel หรือ Localtunnel ได้:
```bash
# หน้าต่างที่ 1: รันเว็บเซิร์ฟเวอร์
python -m http.server 8000

# หน้าต่างที่ 2: สตรีมลิงก์ HTTPS ชั่วคราว
npx localtunnel --port 8000
```
เปิดลิงก์ `https://xxxxxx.loca.lt` บนสมาร์ทโฟน
